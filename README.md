# TITANIC---EXECUTIVE-DEMOGRAPHIC-SURVIVAL-INTELLIGENCE
# RMS Titanic: Executive Demographic & Survival Intelligence Dashboard

An interactive Data Analysis and Power BI dashboard providing insights into passenger demographics, ticket metrics, and survival outcomes from the historic RMS Titanic dataset.

---

## 📌 Project Overview

This repository contains a comprehensive data analysis project and Power BI dashboard designed to evaluate key factors influencing survival rates aboard the RMS Titanic. The analysis explores passenger socio-economic status, age-sex demographic pyramids, embarkation ports, cabin deck distributions, and family groupings.

---

## 📊 Dashboard Key Metrics & Highlights

- **Total Passengers Analyzed:** 891
- **Total Survivors:** 342
- **Overall Survival Rate:** 38.38%
- **Average Fare Paid:** ₹32.20

### Key Insights
1. **Survival by Passenger Class:**
   - **Upper Class (1st Class):** Highest survival rate at **62.96%** (37.04% non-survived).
   - **Middle Class (2nd Class):** Balanced survival rate at **47.28%** (52.72% non-survived).
   - **Lower Class (3rd Class):** Lowest survival rate at **24.24%** (75.76% non-survived).

2. **Demographics:**
